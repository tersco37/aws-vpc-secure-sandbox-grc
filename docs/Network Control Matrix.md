# AWS VPC Network Control Matrix

This document maps the exact Terraform infrastructure code (`main.tf`) for `project2-sec-assessment-vpc` to enterprise GRC frameworks, detailing trust boundaries, routing logic, and security postures.

| Control ID | Terraform Resource Block | Scope / CIDR Block | Security Configuration & Design Intent | GRC Evaluation & Framework Mapping |
| :--- | :--- | :--- | :--- | :--- |
| **NET-01** | `aws_vpc.main` | `10.0.0.0/16`<br>*(project2-sec-assessment-vpc)* | Establishes the primary virtual network boundary with DNS hostnames and support enabled. | **Perimeter Definition**: Isolates sandbox resources from external corporate or public networks. Mapped to *NIST SP 800-53 SC-7 (Boundary Protection)*. |
| **NET-02** | `aws_subnet.public_1`<br>`aws_subnet.public_2` | `10.0.1.0/24`<br>`10.0.2.0/24`<br>*(Multi-AZ)* | Public edge subnets mapped dynamically across available availability zones. | **Controlled Exposure**: Configured for edge workloads requiring direct routing to the Internet Gateway. | **NET-03** | `aws_subnet.private_1`<br>`aws_subnet.private_2` | `10.0.101.0/24`<br>`10.0.102.0/24`<br>*(Multi-AZ)* | Isolated internal subnets with no direct route to the Internet Gateway. | **Strong Isolation**: Mitigates lateral movement and external attack vectors. | **NET-04** | `aws_internet_gateway.gw`<br>`aws_route_table.public` | `0.0.0.0/0` via IGW | Dedicated public route table associating public subnets while leaving private subnets unrouted to the IGW. | **Traffic Flow Enforcement**: Prevents accidental exposure of backend subnets. | **IAM-01** | `aws_iam_role.flow_log`<br>`aws_iam_role_policy.flow_log` | Scoped to Log Group ARN | Restricts CloudWatch permissions strictly to log stream creation and log event publication for this specific VPC. | **Least-Privilege Access**: Prevents excessive IAM permissions for logging services.
